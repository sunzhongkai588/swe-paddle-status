**21 条复现通过不等于新增 21 条正式可评测。** 本轮没有授予新版正式评测资格，也没有升级排行榜资格。历史记录中的 55 条“可直接评测”全部属于本轮未修改、未重跑的范围，只保留原快照的历史结论；不能将其自动升级为新版流程资格，也不能直接与本轮 21 条相加得到正式可评总数。

F2P 是同一有效测试节点在 Base 失败、Gold 通过；P2P 是同一有效节点在两态均通过。下表数字来自重复验证的稳定配对；skip、收集错误、无效 setup 和 CPU 空跑不计通过。未通过任务中的数字可能只是有效子集，须连同备注阅读。

## 必改与未完成项

复现通过但原包需修的 3 条：

- **41202**：修正测试入口和模块布局，消除 python.paddle 导入及生成 proto 依赖阻塞。
- **59127**：把必要的测试模块搜索路径写入原入口或锁定环境，解决 white_list 收集错误。
- **59383**：修复入口路径及文件执行方式；当前通过来自不改断言的分文件受控运行。

验证未通过的 5 条：

- **58323**：延后目标 API 的顶层访问，让 Base 真正收集目标节点；隔离静态模式并修复入口路径。
- **59973**：修复两个 scatter 静态回归的初始化与状态隔离，保留完整回归后重跑。
- **64519**：既要修复测试状态污染，也要补齐兼容的运行环境。ABI 错误不能计为有效 F2P/P2P，也不能当作任务语义失败。
- **73122**：测试必须真正触发 Base 缺陷，不能以“两态脚本退出码都为 0”冒充 F2P。
- **76873**：拆分 legacy/symbolic 入口并固定正确导入，补齐 CINN 符号形状环境；审查 SELU inplace 数值失败，不能直接豁免。9/14 只表示拆分后的有效子集，原混合入口 Base/Gold 退出码均为 4。

环境未完成的 2 条：

- **64881**：替代环境已经尝试全量补验，但完整回归在 Base/Gold 双轮均崩溃，Gold 两个静态节点还存在旧 IR 与新 PIR 类型不兼容。需要恢复匹配的运行环境或构建相应原生版本；仅改测试入口不够。
- **79386**：对应 Base 的原生续编到 pybind 阶段仍超时，未产出可用于本题的安装包，尚未完成 Base/Gold 双轮测试。缓存保留，后续须完成真实原生构建；不能用未重编译的版本代替。

全部 13 条兼容证据通过项还需匹配运行时／依赖资格验证，不能仅因“原包无必改”而自动放行。33369、36684 的依赖文档建议与上述 3 条原包必改分别统计。
