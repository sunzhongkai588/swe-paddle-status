## 发布到 GitHub Pages

1. 将本目录推送到一个 GitHub 仓库的 `main` 分支。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. Branch 选择 `main`，目录选择 `/docs`，保存。

之后每次更新 `main/docs`，GitHub Pages 都会自动重新发布。

## 验证页面

```bash
node --test tests/*.test.cjs
```

可设置 `SWE_PADDLE_SEALED_RESULT` 指向本地封存报告，启用逐题源数据核对；
未设置时该项明确跳过。不要把私有源报告提交到本站仓库。

真实浏览器检查使用 `node tests/browser-smoke.cjs`，由外部测试环境提供
Playwright、浏览器和中文字体，不向本站引入生产依赖。默认启动并关闭临时本地
服务器；设置 `SWE_PADDLE_STATUS_URL` 可复验线上页面，设置
`SWE_PADDLE_SCREENSHOT_DIR` 可将截图保存在仓库以外。

在 `docs` 目录运行 `sha256sum -c validation-update-20260909.sha256` 可核对本轮
公开数据、报告与页面资源。页面资源修改后必须同步生成新的校验清单。

发布前还需检查浏览器控制台、状态筛选、任务详情、移动布局和资源加载。
推送后核对 GitHub Pages 构建对应的提交以及线上文件内容，不能把“已推送”
直接当成“网页已更新”。
